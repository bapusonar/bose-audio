# Bose Audio React Project

React + Vite + TypeScript starter project for the Bose Audio independent repair website.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, normally `http://localhost:5173/`.

## Build

```bash
npm run build
```

## GitHub

```bash
git init
git add .
git commit -m "Initial React project"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```
