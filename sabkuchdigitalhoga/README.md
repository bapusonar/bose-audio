# Sabkuch Digital Hoga — Stage 1

Next.js App Router homepage for https://sabkuchdigitalhoga.com.

## Run locally
Requires Node.js 20.9+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Stage 1
Responsive homepage, navigation, laptop/desktop/audio service sections, brand panels, process section, about section, booking CTA placeholder and global SEO metadata.
